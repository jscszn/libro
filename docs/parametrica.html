Capítulo 2 Estadística paramétrica

En el capítulo anterior hicimos análisis exploratorio de datos sobre una única base de datos (viviendas de California) con el fin de describir una variable respuesta numérica y sus relaciones con otras características. En este capítulo cambiamos de objetivo: en lugar de explorar, contrastamos hipótesis. Se aplican pruebas de estadística paramétrica (y su contraparte no paramétrica cuando los supuestos fallan) a varias bases de datos distintas, cada una pensada para ilustrar un escenario de comparación diferente: dos grupos independientes, dos grupos independientes con varianzas desiguales, datos pareados, y comparación de más de dos grupos.

El razonamiento se repite en cada base de datos y sigue siempre la misma secuencia:

  1. Resumen exploratorio de los grupos a comparar.
  2. Verificación del supuesto de normalidad (Kolmogorov-Smirnov, Shapiro-Wilk o Lilliefors, según el caso).
  3. Verificación del supuesto de homocedasticidad (igualdad de varianzas), con var.test, Bartlett, Levene o Fligner-Killeen.
  4. Contraste de medias (o medianas) con la prueba correspondiente: t de Student (varianzas iguales o Welch), t pareado, o su alternativa no paramétrica (Wilcoxon/Mann-Whitney).
  5. Tamaño del efecto, cuando aplica.

Además de aplicar cada función de R, en varios puntos reproducimos el cálculo manualmente a partir de la teoría (el estadístico, el p-valor y el intervalo de confianza) para verificar que coincide exactamente con la salida de la función nativa. Esto no es un adorno: es la forma de comprobar que entendemos qué hace la caja negra antes de confiar en ella.

2.1.3.1 Verificación teórica del var.test

var.test() contrasta H0: sigma_sist^2 / sigma_diast^2 = 1 frente a H1: sigma_sist^2 / sigma_diast^2 != 1. Internamente calcula:

  • Estadístico: \(F = s_1^2 / s_2^2\), que bajo \(H_0\) se distribuye como una F de Fisher-Snedecor con \(v_1 = n_1-1\) y \(v_2 = n_2-1\) grados de libertad.
  • p-valor bilateral: \(2 \cdot \min\big(P(F \le f),\ P(F \ge f)\big)\).
  • Intervalo de confianza \((1-\alpha)\) para \(\sigma_1^2/\sigma_2^2\): \(\left(F \cdot \dfrac{1}{F_{1-\alpha/2}},\ F \cdot \dfrac{1}{F_{\alpha/2}}\right)\).

Reproducimos el cálculo a mano:

n1 <- length(dfs)
n2 <- length(dfd)
v1 <- n1 - 1
v2 <- n2 - 1
alpha <- 0.05

# estadístico F = s1^2 / s2^2, se distribuye F(v1, v2) bajo H0
F_calc <- var(dfs) / var(dfd)
F_calc
## [1] 0.9278405
# p-valor bilateral
p_valor_F <- 2 * min(pf(F_calc, v1, v2), 1 - pf(F_calc, v1, v2))
p_valor_F
## [1] 0.7101778
# IC (1-alpha) para sigma1^2/sigma2^2
li_F <- F_calc * (1 / qf(1 - alpha / 2, v1, v2))
ls_F <- F_calc * (1 / qf(alpha / 2, v1, v2))
c(li_F, ls_F)
## [1] 0.6242897 1.3789878

El resultado manual (F = 0.9278, p = 0.7102, IC (0.624, 1.379)) coincide exactamente con la salida de var.test(). Conclusión: no hay diferencia significativa de varianzas, así que se puede usar el t-test clásico con varianzas iguales en lugar de la corrección de Welch.

2.1.4.1 Verificación teórica del t.test (varianzas iguales)

Con varianzas iguales, el estadístico usa la varianza combinada (pooled):

\[S_p^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}, \qquad t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{S_p^2\left(\frac{1}{n_1}+\frac{1}{n_2}\right)}} \ \sim\ t_{(n_1+n_2-2)}\]

xbar1 <- mean(dfs)
xbar2 <- mean(dfd)
s1_2 <- var(dfs)
s2_2 <- var(dfd)

sp2 <- ((n1 - 1) * s1_2 + (n2 - 1) * s2_2) / (n1 + n2 - 2)
gl <- n1 + n2 - 2

t_calc <- (xbar1 - xbar2) / sqrt(sp2 * (1 / n1 + 1 / n2))
t_calc
## [1] 31.88841
p_valor_t <- 2 * (1 - pt(abs(t_calc), gl))
p_valor_t
## [1] 0
t_crit <- qt(1 - alpha / 2, gl)
li_t <- (xbar1 - xbar2) - t_crit * sqrt(sp2 * (1 / n1 + 1 / n2))
ls_t <- (xbar1 - xbar2) + t_crit * sqrt(sp2 * (1 / n1 + 1 / n2))
c(li_t, ls_t)
## [1] 39.36328 44.55275

El cálculo a mano da t = 31.888, p ≈ 0, IC (39.36, 44.55), idéntico a t.test(..., var.equal = TRUE).

2.1.4.2 Aproximación con la distribución normal (Z)

Como \(n_1 = n_2 = 100 \ge 30\), por el Teorema del Límite Central se puede aproximar el contraste con z en vez de t, sin necesidad de varianza combinada:

se_z <- sqrt(s1_2 / n1 + s2_2 / n2)
z_calc <- (xbar1 - xbar2) / se_z
z_calc
## [1] 31.88841
p_valor_z <- 2 * (1 - pnorm(abs(z_calc)))
p_valor_z
## [1] 0
z_crit <- qnorm(1 - alpha / 2)
li_z <- (xbar1 - xbar2) - z_crit * se_z
ls_z <- (xbar1 - xbar2) + z_crit * se_z
c(li_z, ls_z)
## [1] 39.37914 44.53689

El resultado (z = 31.888, p ≈ 0, IC (39.38, 44.54)) es prácticamente igual al obtenido con t, tal como se espera cuando las muestras son grandes: la t de Student converge a la normal cuando los grados de libertad crecen.

2.2.3 Supuesto de homocedasticidad: tres formas de probarlo

var.test(dfi, dfg)
## 
##  F test to compare two variances
## 
## data:  dfi and dfg
## F = 22.277, num df = 99, denom df = 99, p-value < 2.2e-16
## alternative hypothesis: true ratio of variances is not equal to 1
## 95 percent confidence interval:
##  14.9892 33.1095
## sample estimates:
## ratio of variances 
##           22.27745

H0: sigma_inversion^2 = sigma_ganancia^2 frente a H1: varianzas distintas. Además de var.test, existen tres pruebas clásicas de homogeneidad de varianzas para dos o más grupos, que difieren en cómo construyen el estadístico y en su robustez frente a la falta de normalidad:

Prueba Cómo funciona Distribución del estadístico Robustez a no-normalidad
Bartlett Razón de verosimilitudes entre la varianza combinada y las varianzas de cada grupo \(\chi^2\) con \(k-1\) g.l. Baja — muy sensible; si los datos no son normales puede rechazar H0 aunque las varianzas sean iguales
Levene ANOVA de un factor sobre las desviaciones absolutas de cada dato respecto a la media/mediana de su grupo F de Fisher-Snedecor con \((k-1, N-k)\) g.l. Media-alta — al centrar en la mediana es robusta a asimetría y colas pesadas
Fligner-Killeen No paramétrica: rankea las desviaciones absolutas respecto a la mediana \(\chi^2\) con \(k-1\) g.l. Alta — la más robusta de las tres, ideal si hay atípicos o no hay normalidad 
# Bartlett: se basa en la razón de verosimilitudes entre la varianza combinada
# y las varianzas de cada grupo. Muy sensible al incumplimiento de normalidad.
bartlett.test(Precio ~ `Tipo de cuenta`, data = df)
## 
##  Bartlett test of homogeneity of variances
## 
## data:  Precio by Tipo de cuenta
## Bartlett's K-squared = 177.81, df = 1, p-value < 2.2e-16
# Levene: usa las desviaciones absolutas de cada observación respecto a la
# mediana de su grupo y aplica un ANOVA de un factor sobre esas desviaciones.
leveneTest(Precio ~ `Tipo de cuenta`, data = df, center = "median")
## Levene's Test for Homogeneity of Variance (center = "median")
##        Df F value    Pr(>F)    
## group   1   107.2 < 2.2e-16 ***
##       198                      
## ---
## Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
# Fligner-Killeen: prueba no paramétrica basada en los rangos de las
# desviaciones absolutas respecto a la mediana de cada grupo.
fligner.test(Precio ~ `Tipo de cuenta`, data = df)
## 
##  Fligner-Killeen test of homogeneity of variances
## 
## data:  Precio by Tipo de cuenta
## Fligner-Killeen:med chi-squared = 82.798, df = 1, p-value < 2.2e-16

Resultado: las tres pruebas rechazan \(H_0\) (p < 0.001), coincidiendo con var.test() (F = 22.28, p < 0.001). Conclusión: las varianzas de Precio son claramente distintas entre Inversion y Ganancia, por lo que se justifica usar el t-test de Welch (var.equal = FALSE) en vez del t-test clásico.

Levene (centro = mediana) F = 0.3065 2, 18 0.7398
Fligner-Killeen χ² = 0.6398 2 0.7262

Conclusión: las tres pruebas dan p > 0.05, así que no se rechaza \(H_0\). Las varianzas del tiempo de resolución son homogéneas entre las tres escuelas, lo que respalda el supuesto de igualdad de varianzas necesario para aplicar un ANOVA de un factor sobre estos datos.

2.7 Resumen del capítulo

Base de datos Diseño Supuesto de varianzas Prueba aplicada
Presión arterial 2 grupos independientes Iguales (var.test no rechaza) t de Student clásico
Precio por tipo de cuenta 2 grupos independientes Distintas (Bartlett/Levene/Fligner rechazan) t de Welch
Intervención educativa Pareado — t pareado
Peso al nacer / tabaquismo 2 grupos independientes No normalidad Wilcoxon/Mann-Whitney
Tiempo de resolución / 3 escuelas 3 grupos independientes Iguales (paso previo a ANOVA) Bartlett, Levene, Fligner-Killeen
Percepción Q1 (pre/post) Pareado, no normal — Wilcoxon pareado

El hilo conductor de todo el capítulo es que la prueba correcta depende de los supuestos, no de la preferencia por un método u otro: primero se verifica normalidad y homocedasticidad, y solo después se elige entre la prueba paramétrica clásica, su variante robusta (Welch) o su alternativa no paramétrica.
